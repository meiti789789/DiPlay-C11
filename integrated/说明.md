# c11.103：C11 仪表车标手动调节

基于 c11.102 正常源码编译，保持 c11.9 功能基线、包名 com.c11.diplay、固定签名、名称、图标与现有设置。

## 本版改动

C11 仪表设置现在只显示一组实际生效的控件：“C11 仪表车标 · 左右”和“C11 仪表车标 · 上下”。这两个滑块直接保存 C11 仪表流 111 请求实际读取的坐标；隐藏不适用的原上游小屏独立坐标、自动识别、ADB／使用情况授权入口和小屏暂停选项，避免调错。中控流 110 不变，仪表窗口仍为右侧 720×720，不平移或裁切视频。

横向范围与 C11 实际请求限制一致（17–95%），纵向 5–95%，按 1% 步进。左右、上下都以 50% 标为默认中心；“将车辆标记重置到居中”恢复 50/50。保存后普通重启保留，不会在每次重连时归零。先执行旧默认值一次性迁移，再允许手动保存，避免用户恰好调到旧默认组合时再次被覆盖。

调节时只保存，松手后显示待重连提示，不自动打断当前 CarPlay；点击“立即重连”或手动断开再连接后生效。不需要车机 ADB 或使用情况访问。

## 操作

应用内检查更新、下载校验，按车主电脑流程覆盖安装，不清数据。停车进入“设置 → 高级 → 仪表地图”，找到两个带“C11 仪表车标”的滑块。若导航车标偏右，先把左右滑块向左调少量，点击“立即重连”，开始导航后对照仪表右侧车标；再逐步调整上下。可随时恢复默认中心。

## 限制与验证范围

这是调整 iPhone 的位置／安全区请求，不是实时把视频中的车标单独拖动。官方“地图和转向卡”模式中，iPhone 可能同时重排转向卡和地图；实际移动幅度、最终能否正好居中仍需实车验证。保留官方卡片和红绿灯，不擅自切换内容角色。

测试覆盖从实际 UI 滑块保存、经持久化传入 111 请求、重连迁移不覆盖手调、恢复默认、待重连标记且不自动断开，以及小屏错误入口隐藏。包含大字体窄屏、宽屏和阿拉伯语预览（均为模拟界面）。执行上游要求的完整单元测试、三个应用 lint 与构建，全部通过后才发布。

本版不声称解决无声、双屏全览／跟车同步或官方卡片大小。透明效果沿用 c11.102。未执行车机 ADB，不写系统 Global，不改系统、字体、资源或 CAN，不处理此前暂缓的偶发音量变小。
