# DiPlay C11 单 APK 一体测试版

这是完整 CarPlay 主程序与 C11 方控适配的一体 APK，不需要安装旧版桥接，不需要为 C11 广播适配开启通知使用权或使用 ADB。

首个完整一体版已发布：[0.2.21-c11.1 下载页](https://github.com/meiti789789/DiPlay-C11/releases/tag/c11-v0.2.21-c11.1)。上游要求的 3,102 项单元测试、静态检查及构建通过，车机实测仍待完成。不要把旧版 18 KB 的桥接 APK 当成一体版。

**尚未实车验证，默认关闭 C11 转发。** 独立包名 `com.c11.diplay`、名称“DiPlay C11”，使用本项目固定签名。可先保留现有 DiPlay 供回退，但同一时间只运行一个投屏应用。测试一体版时关闭旧桥接转发并撤销其通知使用权，退出原 DiPlay，避免多个程序抢占连接或处理按键。

连接 iPhone 并播放音乐后，进入 设置 → 车辆 → 方向盘按键，找到“C11 方控（实验性）”。先保持关闭，按上一首、下一首、暂停各一次；在诊断页保存报告，查看 C11 接收日志。有匹配记录后再打开开关实测；开关立即生效。检查一次只切一首、暂停与恢复正确、原车音量正常、断开后原车音乐正常。发生异常立即关闭开关，退出一体版并回原版本。转发关闭时仍可在 CarPlay 会话内记录收到的媒体广播。

这只是媒体广播监听，不写 CAN，不控制挡位，不请求额外音频焦点。c11.1 只含方控，c11.2 增加了明确选屏的仪表渲染路径；倒挡联动未纳入；其它功能继承所基于的上游版本，不能保证与参考零跑分支完全相同。原版功能本身的实验性权限或限制仍以对应上游说明为准，不要为测试方控额外授权不相关功能。

## 按车机界面操作的详细步骤

1. 从本项目 Releases 下载名称以 `DiPlay-C11-` 开头的一体 APK，而不是 `C11-WheelBridge-`，也不是未修改的 `DiPlay-0.x.x.apk`。源码 ZIP 与 SHA256 文件不用安装。
2. 停车，通过车机正常文件管理器安装方式安装。应用列表中应出现“DiPlay C11”。包名独立，首次无需卸载原 DiPlay；不需要 ADB。
3. 若以前安装过独立桥接，先在桥接里关闭转发，并在系统通知使用权页面撤销它的权限。可卸载旧桥接；不要把它与一体版同时用于测试。
4. 退出旧 DiPlay，再打开 DiPlay C11；同一时间只运行一套投屏程序。新包的配置与旧版分开，可能需要在新版重新设置原来的有线／无线连接方式、配对手机。保留旧版设置供退回，不要清除旧版数据。具体连接操作与对应上游版本一致。
5. 在 CarPlay 中播放有多首歌曲的音乐列表。通过 DiPlay 自身入口返回设置，进入“车辆”分类的方向盘按键卡片。只操作“C11 方控（实验性）”，不要为此开启无障碍、ADB、仪表或其它高级权限。
6. 第一轮保持 C11 开关关闭，每隔约 2 秒短按一次上一首、下一首、暂停。进入诊断页保存诊断报告，搜索 `C11`。关闭转发时音乐不变是正常的；日志应能区分 `NEXT`、`PREVIOUS`、`TOGGLE` 或 `unmatched`。
7. 收到正确映射后，开启 C11 开关并回到音乐页重复测试。它即时生效，不会为切换这个开关主动断开 CarPlay。确认下一首、上一首、暂停与恢复，以及原车音量。部分音乐应用的上一首先回到当前曲目开头，应结合播放器画面判断。
8. 断开 CarPlay，确认原车音乐与原车按键正常。重复切歌、异常暂停或原车操作异常时，关闭 C11 开关并退出新版；需要时回到原 DiPlay。若无法进入新版设置，可通过系统正常的应用管理停止或卸载 DiPlay C11，再使用原版本。

## 诊断如何看

- `C11 listener attached; forwarding=false`：当前会话已注册监听，转发关闭。
- `C11 … -> NEXT/PREVIOUS/TOGGLE; enabled=false`：收到了对应按键，尚未转发。
- `unmatched`：收到了已监听通道上的事件，但字段不匹配；C11 通道会附上字段值与类型。
- `media key c11-wheel -> CarPlay … sent=true/false`：向 CarPlay 提交按键的结果；仍需结合实际歌曲变化，不能只看 sent=true。
- `C11 duplicate media event suppressed`：250 ms 内的同类重复事件被合并。
- `C11 receiver registration failed`：注册失败，查看后面的错误类型并停止测试。
- 没有任何 C11 事件：先确认 CarPlay 会话建立、按的是媒体键。仍没有时分享诊断，不要猜参数或写入车机。

诊断记录只保留有限条数，请测试后尽快保存。反馈按键顺序、实际反应、DiPlay C11 版本、固件版本与报告。分享前检查账号、车架号、热点密码等隐私；不需要公开这些信息。

## 原车网易云与 CarPlay 的控制关系

车主确认的旧版现象是：原 Leap21_23 中，方控能操作车机网易云，CarPlay 无响应。本版先修复参考源码中可确认的广播注册与字段解析问题，不能据此断言该车的根因已被确认。

监听广播和请求音频焦点不等于能阻止另一个播放器收到相同事件。本版不会擅自关闭整车方控、禁用网易云或修改它的设置。如果实测 CarPlay 开始响应，但网易云也被同步切歌／暂停，请先关闭 C11 转发并反馈；这是仍需验证的播放器互斥问题，不能宣称应用内去重已解决。只有车机或播放器明确提供可用的控制接口，才能进一步做合适的自动切换。

## c11.2 仪表导航与零跑界面

c11.2 增加零跑图标、应用名“零跑 C11”（非中文为 Leapmotor C11），以及明确选屏的 C11 仪表地图路径。版权与技术兼容说明保留真实来源，不会把比亚迪专用接口改名冒充零跑功能。C11 平台上隐藏未适配的其它车型控制，并关闭比亚迪 ADB 仪表路由。

仪表适配还未实车验证。它只使用 Android 已公开的 presentation 屏幕，不绕过私有屏幕权限，不修改系统显示布局，不写 CAN。候选必须是非主屏、非私有、1920×720 的公开投影屏；**同尺寸不代表一定是仪表，不可据尺寸随意选择副驾屏**。

1. 先完成中控 CarPlay 音乐和方控的基础检查。
2. 设置 → 高级 → 仪表地图，查看“C11 仪表屏幕（实验性）”。默认未选择，不会自动把任意屏幕当仪表。
3. 如果没有候选，或者无法确认哪个是仪表，保持未选择，保存诊断报告。报告已有全部可见屏幕、公开投影列表、C11 候选与选择信息。此时不能宣称仅靠此版本就能显示仪表，也不自行用 ADB 强制授权。
4. 只有确认该候选属于仪表后才选择。选择只保存配置，按界面提示重新连接 CarPlay；主“仪表地图”开关也必须开启。不会未经确认重连。
5. 停车，用 iPhone 自带地图先发起一次导航。仪表流固定为 720×720，窗口限定在已知面板右侧 720×720 区域，透明底、不接收触摸、不抢焦点；不会把整个 1920×720 面板铺成地图。实际是否保持原车所有信息可见仍需停车核实，不能仅凭代码保证。
6. 检查主驾速度、警告等原车信息是否正常，地图是否出现且比例正确。有遮挡或其它异常立即关闭仪表地图；必要时退出一体版，回原程序。
7. 屏幕编号可能在重启后变化；已保存的名称和编号都需匹配，重名或消失时不自动换成另一块屏。失效时先导出诊断，再确认是否需要重新选屏。

目前没有你的实际 display 列表，不能保证仪表屏对普通应用开放。显示窗口、地图流和选屏路径的电脑验证不等于该车已投屏成功。HUD 转向提示、挡位和 CAN 联动未纳入本次适配。

品牌图标同时覆盖应用图标、主界面、默认 CarPlay 返回车机图标与名称。旧默认 BYD 名称会读取为“零跑”，其它自定义名称保留；若你曾选过自定义图标，需在车机按钮设置中恢复默认后重连 CarPlay，更新不会擅自清除你选择的文件。
