# c11.100：C11 集中修复验证版

以 GitHub c11.9 功能为基线正常源码编译，保留包名 com.c11.diplay、固定签名、名称、图标、显式保存的设置、仪表 #2 选择与实际视频帧到达前透明等待。未恢复硬斜边，不改车机系统、字体、系统资源或 CAN，未执行车机 ADB。

本轮修改：

- 音乐：收到按键时立即检查原车媒体会话；在记录原车原先播放状态后提前建立 CarPlay 媒体会话。只有音乐互斥已启用、活跃 CarPlay 会话已接受按键转发入队且广播为有序广播时，才阻止其继续传给后续原车接收器。普通广播、原车服务直接启动网易云的路径无法靠该接口取消，仍可能漏音；不能宣称已根除。断开后的原车音乐恢复策略保留，不静音整个媒体流。
- 仪表：解码器使用流 111 自己协商的尺寸，不再沿用中控 110 的尺寸。地图左侧 12% 为平滑透明过渡，显示下方真实原车背景，白天和夜间不依赖猜测底色。安全区域避开过渡区域；未手动设置的车标位置默认处于剩余区域中心。显式设置不覆盖，窗口仍为右侧 720×720，不裁切或移动整幅视频。
- 通话：C11 持续读到全零录音数据时，最多两次关闭本录音器附加的音效并重启同一录音源，保留连接、编码器和 RTP 计数。没有要求重复切换三种录音源，也不更改系统麦克风静音或蓝牙开关。日志增加 SCO 和可用输入信息。这是针对已有证据的恢复措施，不能保证修复系统录音占用或 iPhone 选择了车机蓝牙的情形。
- OTA：保留 c11.99 的数字排序选择与完整性校验。已安装 c11.99 可直接检查本版；旧 c11.9 的列表首项仍可能是 c11.99，需要先从应用内更新到过渡版，再在应用内检查本版。白名单安装由车主在电脑端处理，不要求 U 盘。

地图视角同步的边界：中控是 iPhone 流 110，仪表是独立流 111，现有仪表命令支持放大/缩小，但没有已验证的全览/跟车切换及状态回传接口。本版保留“地图和官方转向卡”以及红绿灯能力，不把两路画面称为天然同步，也没有伪造一套未验证的私有命令。该问题未解决。

停车验收：连接 CarPlay，分别试播放/暂停、上一曲、下一曲并检查原车是否启动或漏音；断开后检查原先音乐恢复。检查仪表位置与昼夜左缘过渡。通话时在 iPhone“音频”中确认选中 CarPlay，若仍无声导出一次诊断报告，无需重复尝试录音源。测试、截图和构建通过均不代表实车已验证；本版不能标为全部问题已经解决的最终版。
