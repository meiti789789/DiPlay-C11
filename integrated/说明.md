# c11.101：仪表右侧地图居中请求修正

本版承接正常源码编译的 c11.100，功能基线仍为 GitHub c11.9。修改只作用于 C11 已确认仪表输出的流 111：右侧窗口仍为 720×720，保持原包名、固定签名、名称、图标和官方“地图和转向卡”模式。

此前把避开左侧渐变后的 56% 横向位置当作默认中心，会给仪表中心请求引入向右偏置。本版改为整个右侧 720×720 区域的 50% / 50%，默认安全区左右、上下分别对称。地图可以继续绘制在安全区外，不移动仪表窗口，不缩放或裁切整幅视频来伪装居中。

仅首次创建仪表流时处理旧版默认组合：56/50 和 50/45 归正为 50/50，并在本应用配置中保存原坐标。其他自定义偏移保留，之后重新连接不反复覆盖用户设置。现有“将车辆标记重置到居中”按钮随新默认值变为 50/50。仪表连接日志增加实际请求的安全区、内容 URL 与坐标，便于对照 iPhone 实际输出。

中控流 110 的配置和触摸映射保持原样。音乐、通话、渐变实现沿用 c11.100；不写系统 Global，不改字体、系统资源或 CAN，不执行车机 ADB。

操作：断开 CarPlay 并联网 → 关于 → 检查更新 → 下载校验。白名单安装仍由车主在电脑端处理。2026-10-22 已按 c11.9 的 URL、User-Agent 和 Accept 发出不带认证的公开请求，首项为完整 c11.101；c11.9 当前可发现本版，c11.99/c11.100 的数字扫描也可选择本版。若旧客户端因缓存仍先提示 c11.99，可先完成过渡更新再检查。不卸载、不清数据、不要求 U 盘。

覆盖安装后重新连接 CarPlay。如果曾手动调整车标偏移，先在仪表设置点击一次“将车辆标记重置到居中”，再重新连接。只检查仪表右侧地图，中控无需调节。

软件测试仅验证请求参数、旧值迁移和中控配置隔离。iPhone 在官方转向卡占位后是否将实际车标画到预期位置，仍需实车确认；若仍偏位，不能把安全区参数居中说成实车已解决。此前反馈的左缘未融合和双地图视角同步缺口也不能据此宣布解决。
