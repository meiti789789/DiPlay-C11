# C11：同步上游发布，保留零跑适配

首个 0.2.22 适配版本为 `0.2.22-c11.105`（41105），上游提交为 `28d6002ba00320f0ba745212160b08759e4f60b9`。后续自动同步继续递增 C11 编号；本次实际版本与提交以发布标签及附件 `c11-build.json`、`upstream.json` 为准。所有版本正常源码编译，保持包名、固定签名、名称、图标及现有设置；不需要卸载旧版或清除数据。

上游修正包括无线音乐时钟偏快及卡顿、Android 8/9 无线断线检测、Wi-Fi Direct 旧连接恢复、通话结束后的音频状态恢复，并增强麦克风诊断。USB 录音分包修正不代表本车无线通话已解决。

保留 C11 方控、断开后原车音乐恢复、仪表 #2 选屏与保存、右侧区域投影、实际视频帧到达前透明、地图和官方／自定义转向卡、190% 卡片上限、左缘平滑透明融合，以及车主手动设置的车标坐标。

本次只同步上游与适配接口，不新增原车音乐启动阻断。方控播放／暂停仍可能唤起原车音乐，现有互斥只是请求暂停；不能宣称已彻底解决。昼夜主题切换中断按车主要求暂不处理，不修改系统媒体源变量或 CAN，不执行车机 ADB。

GitHub 定时检查已暂停；手动运行工作流时检查完整上游发布；新上游版本继续递增 C11 编号，同版本每日检查不重复发布。完整测试、三个应用 lint／构建及签名验证通过后才发布；失败时保留旧版并通过 GitHub Issue 通知。发布后验证实际公开 OTA 接口的数字排序、旧 c11.9 首条及 APK 下载 SHA256。

# c11.104：自定义转向卡翻倍与仪表左缘柔和融合

从已发布 c11.102 正常源码编译。此前 c11.103 手动车标改动已按车主要求取消，本版不恢复它；保留车主已经调好的仪表车标坐标。

C11 的“自定义转向卡大小”与“小屏转向卡大小”最大值由 95% 扩展为 190%，步进保持 5%。190% 档以旧 95% 档实际像素尺寸为基准，宽、高各放大到 2 倍，文字、箭头与下方到达信息条同步放大。修正仅改百分比仍可能被旧高度上限挡住的问题，保证实际画出的卡片增大。原 30–95% 档的像素尺寸、默认大小和已保存数值保持不变；非 C11 设置仍显示原范围。

在 720×720 仪表区域，旧最大主卡为 197×74 像素，新最大为 394×148 像素；信息条按旧实际最小高度同步翻倍。卡片边界保持在本应用仪表窗口内。没有放大整幅地图，也不移动车标、窗口或原车信息。

## 仪表左缘融合

按车主提供的夜间原车导航照片，以去掉明显矩形边界、柔和透出底层背景为目标：视频左缘从原 12% 窄线性过渡改为 24% 宽的平滑透明过渡，两端斜率趋零。上下使用完全相同的遮罩；不恢复硬斜边、不裁切或平移视频。不填充固定黑色／白色，白天、夜间均透出实际原车底层。

24% 是本版视觉过渡配置，并非从照片精确测得的原车遮罩。真实底层背景、车机视频合成和拍摄曝光都会影响观感，不能保证照片像素级复刻。视频视觉羽化与 iPhone 安全区分开，原 12% 安全区参数及车主手调车标坐标保持不变；本地自定义转向卡不套视频遮罩。

## 操作

关于 → 检查更新 → 下载校验，按车主现有电脑流程覆盖安装，不卸载、不清数据。继续使用“地图和自定义转向卡”模式，把“自定义转向卡大小”滑到新的最大 190%。旧 95% 设置会保留，需要主动向右调整；大小设置沿用现有即时刷新链路，无需重新调整车标。若使用独立小屏转向卡大小，也可调到 190%。

本版保持包名 com.c11.diplay、固定签名、名称、图标和原设置。完整单元测试、三个应用 lint 与构建通过后才发布。测试覆盖旧尺寸不变、新最大实际宽高翻倍、字体及信息条字号同步放大、位置边界、保存读取和真实 UI 滑块；提供大字体窄屏、宽屏、阿拉伯语及新旧实际卡片模拟预览。软件尺寸验证不等于实车显示已确认。

原车音乐仍被方控启动后又暂停／退下的问题没有根治：现有互斥是启动后请求暂停，不能保证阻止原车收到同一按键。CarPlay 按键正常也不能证明原车已被拦截。本版不擅自写 LAST_PLAY_MEDIA_TYPE，不用全局静音，不声称已消除启动／漏音。无声、双屏视角同步和昼夜融合的实车状态也不据此宣布解决。

未执行车机 ADB，不改系统、字体、资源或 CAN；不恢复已取消的手动车标改动，不处理此前暂缓的偶发音量变小。
