# c11.99：供已安装 c11.9 使用的 OTA 过渡版

以 GitHub c11.9 源码为基线正常编译完整 APK，保持 com.c11.diplay 包名、固定签名和现有配置。不是二进制重打包。地图、方控、音乐互斥和通话实现均保留 c11.9 行为；不加入已经撤回的斜边。

版本号特意由 9 提高到 99，使旧客户端读取发布列表第一条时也能发现本版；APK 内实际版本号同样是 0.2.21-c11.99 / 40099。发布后必须实查旧客户端使用的接口第一条确实为本版，不能仅凭网页“最新”标签保证 OTA。

本版修正更新选择：扫描返回列表并按数字版本选择最新完整发布，跳过草稿和缺 APK/校验文件的条目。99→100 的回归测试已包含。后续版本仍需手动确认安装；此更新不是 LeapOS 固件升级，也不能绕过车机安装白名单。

车机端：断开 CarPlay 并保持联网 → 零跑 C11 → 关于 → 检查更新 → 下载并等待校验完成。不卸载、不清配置。车主已说明，白名单安装需要由自己在电脑端导入、上传后处理；软件内 OTA 的本轮核验范围为发现更新、下载与校验，不把下载完成当作车机安装成功，也不要求另用 U 盘。

待继续处理：仪表车标居中、中控/仪表独立地图视角差异、昼夜渐变边缘、原车网易云按键联动和短暂漏音、CarPlay 通话无声。本版首先建立来自 c11.9 的正常编译 OTA 路径，不声称这些实车问题已修复。
