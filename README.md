## 首次使用

1. 停车，通过车机正常 APK 安装方式安装一体版。无需 ADB。
2. 新包名为 `com.c11.diplay`，使用本项目自己的固定签名。可先保留原 DiPlay 作为回退，**不要同时运行两套投屏应用**。一体版自身不依赖旧版；验证通过后是否卸载旧版由车主决定。
3. 如果装过旧桥接，关闭它的转发并撤销其通知使用权。C11 一体适配本身不需要通知使用权或无障碍权限；主程序原有其它功能的权限以相应设置说明为准。
4. 打开“零跑 C11”，按原有方式配置并连接 iPhone，播放音乐。新包配置独立，不能假定会自动继承旧包配对或设置。
5. 设置 → 车辆 → 方向盘按键 → **C11 方控（实验性）**。先保持关闭，分别短按上一首、下一首、暂停，在诊断报告中查看 C11 记录。
6. 确认有正确事件后再打开开关，检查每次只切一首、暂停与恢复、原车音量及断开后的原车音乐。异常时关闭开关、退出新版，回原版本。

音乐互斥需额外手动开启“零跑 C11”的通知使用权，再打开“CarPlay 原车音乐互斥（实验性）”。它请求暂停受支持的本机音乐会话，不修改系统音量；断开时只尝试恢复开始监听前正在播放且被本功能暂停的同一会话。默认关闭，不支持的播放器仍可能双响。详见指南。

已安装 c11.2 的用户可在 **设置 → 关于 → 检查更新** 下载新版并确认安装，无需每次使用 U 盘；车机需能访问 GitHub。

完整的字段解读、日志反馈、更新和回退方式见 [详细使用说明](使用说明.md)。不能保证普通广播被本应用监听后，车机网易云就不会再收到；播放器互斥仍需实车验证，不应通过全局禁用整车方控处理。

通话无声的 C11 用户：先挂断，进入 **设置 → 高级 → 视频与音频 → C11 通话录音源（实验性）**，选择“语音识别录音源”，下一次通话生效。默认保留上游来源；无效可恢复默认，不修改系统路由。此选项基于实车通话录音全零、而 Siri 可识别的反馈提供，不能预先保证修好。

## 与旧零跑分支的关系

参考发布版存在可核实的适配缺口：两个整型 extra 通道定义但未注册；C11 的 value 只读取字符串；NOT_EXPORTED 对 OEM 媒体进程的接收范围也需核对。新实现注册全部已知媒体通道、兼容字符串与整数、记录通道与字段类型，并将原生媒体键与广播共用 250 ms 去重。

这些源码事实尚不能直接证明该车真实根因。车主实际反馈是原车网易云响应而 CarPlay 无响应，故首要验证 DiPlay 的接收、解析和转发。

一体版以原始上游主程序为基底，方控协议参考零跑分支，仪表采用本项目明确选屏与限定窗口的实现；未加入倒挡联动或 CAN 心跳。其它功能继承相应上游版本，不能宣称与参考零跑分支完全相同。设备图片显示 Android 9 / API 28、msmnile_gvmq、qti、arm64-v8a；具体固件号及真实通道仍需诊断确认。

## 更新方式

- 应用内更新源是本仓库的一体版发布。已跳过历史桥接／原版组合包，避免下载成不兼容类型。
- 上游版本号和本项目 `c11.修订号` 都参与更新比较。同签名的一体版可正常尝试覆盖更新；不能用上游作者签名的原版 APK 覆盖本包。
- 自动工作流每 6 小时检查上游发布（含预发布），对精确发布标签重新应用补丁。锚点不匹配、测试或校验失败时停止，不发布未通过检查的新包。
- 自动流程是构建、检查与发布，不是车机静默安装；最终更新安装需要用户确认。
- 永久兼容未来上游与车机固件无法保证。检查成功也不代表实车按键、通话、无线连接等全部场景验证完成。

## 验证与源码组织

c11.11 云端通过上游 AGENTS.md 要求的完整命令：shared 1,605 项、common 1,551 项、home 6 项，共 3,162 项单元测试，0 失败、0 跳过；三个应用模块的 lint 与调试构建通过，然后才构建发布签名包。新增测试覆盖 Android 9 / 13 下的默认关闭、会话释放、音乐暂停与恢复、错误权限状态、同名屏幕绑定、重启后保留与固件/拓扑变化后失效，以及方控、地图流、窗口尺寸、品牌和在线更新。测试未连接车机，未执行车机 ADB。

`integrated/overlay` 为新增适配与测试，`integrated/prepare.py` 校验并修改上游语义锚点。完整可复现的已适配上游源码随每个一体版发布附带。设置页预览使用 Robolectric 原生图形模式，属于电脑模拟结果，不能当作实车截图。

早期独立桥接的源码仍保留在 `app/`，说明见 [历史桥接指南](docs/旧版桥接使用说明.md)。旧组合包同步改为手动触发。
